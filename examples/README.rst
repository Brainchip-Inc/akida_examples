Akida examples
==============
To learn how to use Akida, the QuantizeML and CNN2SNN toolkits and check the Akida accelerator
performance against some commonly used datasets please refer to the sections below.

For more self-contained projects covering training, conversion and deployment on Akida
hardware, check out the `BrainChip DevHub <https://github.com/Brainchip-Inc/brainchip_devhub>`_
repository.
